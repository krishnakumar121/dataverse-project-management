# User Guide

## Getting Started

### Accessing the App

1. Go to [Power Apps Portal](https://make.powerapps.com)
2. Click "Apps"
3. Find "Project Management App"
4. Click to launch

### First-Time Setup

1. **Review Dashboard** - Get overview of current projects
2. **Explore Navigation** - Familiarize yourself with menu
3. **Create Sample Project** - Practice with test project
4. **Read Help** - Access in-app help and documentation

---

## Creating a Project

### Step-by-Step

1. Click **New Project** button
2. Fill in project details:
   - **Project Name** (Required): Unique identifier
   - **Description**: Project overview
   - **Start Date** (Required): Project begin date
   - **End Date** (Required): Planned completion
   - **Status** (Required): Select "New" or "Active"
   - **Priority** (Required): Select level
   - **Budget** (Optional): Total budget amount
   - **Owner** (Required): Project manager name
   - **Client/Department** (Optional): Organization info
3. Click **Save**
4. Project created and ready for tasks

---

## Adding Tasks

### Create Task

1. Open project
2. Go to **Tasks** tab
3. Click **New Task**
4. Enter task details:
   - **Title** (Required): Task name
   - **Description**: Task details
   - **Status** (Required): Select status
   - **Priority** (Required): Select priority
   - **Due Date** (Required): Deadline
   - **Assigned To** (Required): Team member
   - **Estimated Hours**: Expected effort
5. Click **Save**

### Update Task Status

1. Open task
2. Click **Status** dropdown
3. Select new status:
   - New → In Progress
   - In Progress → Blocked or Completed
   - Blocked → In Progress (after resolving)
4. Click **Save**

---

## Managing Team Members

### Add Team Member to Project

1. Open project
2. Go to **Team** tab
3. Click **Add Team Member**
4. Select team member from list
5. Enter allocation details:
   - **Role**: Position on team
   - **Hours**: Hours allocated
   - **Start Date**: When they join
6. Click **Save**

### Track Resource Utilization

1. Go to **Resources** view
2. Filter by team member
3. See total hours allocated
4. Check utilization percentage
5. Reassign if overutilized

---

## Tracking Milestones

### Create Milestone

1. Open project
2. Go to **Milestones** tab
3. Click **New Milestone**
4. Enter details:
   - **Milestone Name**: Identifier
   - **Target Date**: Due date
   - **Status**: Current status
   - **Key Deliverables**: What's being delivered
5. Click **Save**

### Track Progress

1. Go to **Milestones** view
2. See status of all milestones
3. Check dates and deliverables
4. Get alerts when due

---

## Risk Management

### Identify Risks

1. Open project
2. Go to **Risks** tab
3. Click **New Risk**
4. Enter risk details:
   - **Description**: Risk statement
   - **Impact**: Potential consequence
   - **Probability**: Likelihood
   - **Mitigation Plan**: Response strategy
   - **Owner**: Responsible person
5. Click **Save**

### Monitor Risks

1. View **Risk Dashboard**
2. See high-risk items highlighted in red
3. Review mitigation plans
4. Update status as risks change
5. Close when mitigated

---

## Viewing Data

### Use Filters

1. Go to any view (Projects, Tasks, etc.)
2. Click **Filter** icon
3. Select filter criteria:
   - Status = Active
   - Priority = High
   - Owner = [Your name]
4. Click **Apply**

### Sort Data

1. Click column header
2. Select sort direction (ascending/descending)
3. Data re-sorts automatically

### Search

1. Use **Quick Find** box
2. Type search term
3. Results filtered in real-time

## Notifications

### Email Alerts

Receive alerts for:
- Tasks due soon
- Milestones approaching
- High-risk items
- Project status changes

1. Go to **Settings**
2. Choose **Notifications**
3. Select what to be notified about
4. Set frequency (real-time, daily, weekly)
5. Click **Save**

## Common Tasks

### Closing a Project

1. Complete all tasks
2. Resolve open risks
3. Get stakeholder sign-off
4. Change status to **Closed**
5. Add completion notes
6. Archive (optional)

### Reassigning a Task

1. Open task
2. Click **Assigned To**
3. Select new team member
4. Click **Save**
5. New assignee notified

### Escalating a Risk

1. Open risk record
2. Click **Escalate**
3. Risk marked as critical
4. Escalation email sent
5. Track in escalation queue

## Troubleshooting

### Can't Find a Project

- Check if archived
- Clear filters
- Use search function
- Check your access permissions

### Task Not Showing

- Verify project selected
- Check filters applied
- Ensure row-level security
- Refresh page

### Email Not Received

- Check notification settings
- Verify email address
- Check spam folder
- Contact administrator

### Mobile App Issues

- Update Power Apps app
- Clear app cache
- Sign out and back in
- Check internet connection
